# 机器人示范数据质量审计与成功预测

这是面向 AI 数据／算法工程岗位的独立工程研究项目。主线是公开真实数据的审计与预测，另设一个人工污染的仿真实验检验清洗效果。

## 已完成的实测工作

- 审计 15,000 条 DROID 示范，使用 LeRobot v3 社区转换版；隔离上游 36 个成功／失败标签冲突的 UUID 后再抽样。
- 使用 156 个前 30 帧运动特征，按采集者分组，比较常数基线、逻辑回归与 LightGBM。
- 测试 AUC：逻辑回归 0.648、LightGBM 0.592、常数基线 0.500。按验证集失败 PR-AUC 选择的是 LightGBM，报告保留这个模型在测试集上的下降。
- 抽样解码 30 条左侧外部相机视频，帧数核对通过；不代表全量视频或原始设备时钟质量。
- 15 项研究控制测试通过；D 盘独立环境也通过测试，并对两个真实留出样本重新生成特征、复核三种模型的推断。
- Lift 人工动作污染实验完成五组 × 三个训练种子 × 100 次评测，共 1,500 次仿真。所有策略使用 60,000 步预算和匹配初始状态。
- 成功率：干净组 61.3%、污染组 22.7%、随机剔除组 15.0%、审计剔除组 57.7%、依据注入答案剔除组 62.3%。审计相对污染组提高 **35.0 个百分点**，95% 配对双向聚类自助法区间为 **21.0–48.7 个百分点**。
- 逐条汇总与 15 份云端原始评测日志一致；独立 NumPy 实现重算均值和 2,000 次重采样区间通过。仿真结果不能写成真实 DROID 或实体机器人提升。

## 运行

Windows 下将项目保存在 D 盘，按英文 README 的 PowerShell 步骤运行。`scripts/run.ps1` 统一配置环境、缓存与临时路径；解析后的写入路径离开项目或指向非 D 盘时停止。原始数据、模型和视频不进入 Git 仓库。

`notebooks/00_project_runner.ipynb` 用于阅读或复现实测流程；`notebooks/01_colab_policy.ipynb` 用于云端策略实验。云端固定运行时版本 2026.07（Python 3.12）。首次安装更换 NumPy 后，按提示重启会话再全部运行，避免旧内核混用二进制依赖。

只核验已发布策略结果时，运行 `python -B scripts/verify_policy_results.py`，无需下载模型、安装仿真器或再次训练。它核对完整逐条记录、匹配状态、预算、独立试跑、注入答案隔离记录，以及成功率和不确定性区间。
